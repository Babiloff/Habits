## Карточка привычки (по Клиру, обе дорожки)

Полезная:
```
Привычка: ...                     Столп: ...
Identity: я человек, который ...
Очевидно:  после [старая привычка] → [новая]. Где: ... Когда: ...
           среда: что лежит на виду: ...
Привлекательно: после [новая] → [приятное]: ...
Легко:     минимальная версия (≤ 2 мин): ...   полная версия: ...
           подготовить заранее: ...
Приятно:   отметка в трекере; серия; «не пропускай дважды»
```

Вредная (нейтрализация):
```
Привычка: ...                     Столп, который страдает: ...
Сигнал (когда и где тянет): ...
Что даёт на самом деле / чего лишает: ...
Невидимо:   убрать сигнал: ...
Непривлекательно: фраза-напоминание: ...
Трудно:     трение: ...
Неприятно:  кто видит срыв: Claude в 21:30; последствие: ...
Замена:     вместо [вредная] → [полезная или нейтральная], тот же сигнал
```

## Правило столпов

Не все шесть столпов каждый день. Иначе план превращается в «всё понемногу», а такой день ты сам описал как пустой.

| Ритм | Столпы | Как |
|---|---|---|
| Каждый день | здоровье, семья, плюс базовая привычка (вечерний план) | микро-якоря, 2–5 минут |
| Каждый день | столп главной задачи | один блок времени на главную задачу |
| Недельный минимум | социальная жизнь, духовное, досуг, карьера сверх главной задачи | число раз в неделю, распределяется в воскресенье |

Ответ на твоё сомнение про социальную жизнь: оба варианта верны, и мы их совмещаем. Микро-версия «одно сообщение другу» может быть ежедневной привычкой, если социальный столп окажется среди самых слабых. Полная версия «встреча или звонок» живёт как недельный минимум.

## Вечерний план на завтра. 21:30, 10 минут

Пишется в чат в ответ на мой вопрос. Пять строк, не больше.

```
1. Главная задача: <одна>. Первый шаг (≤ 15 минут): <...>
2. Блок: <во сколько и где делаю главную задачу, с какого по какое время>
3. Ещё: <2–3 второстепенные задачи, без них день всё равно зачёт>
4. Якоря: <после [старая привычка] → [новая]>, по строке на привычку. Пока список не утверждён, одна строка: после ужина → план на завтра
5. Риск: <если ...> → тогда <...>
```

Первые дни, пока ликбез не прочитан и привычки не выбраны, я не ставлю баллов. Только подсказываю, какой строки не хватает.

Источники:
- Одна главная задача, первой в день. Трейси, «Съешьте лягушку». Для тебя особенно: главная задача даёт то самое «продвинулся к цели», которого нет в дне «всё понемногу».
- Блок времени, не пункт списка. Ньюпорт, тайм-блокинг. Задача без времени и места не выполняется, она остаётся намерением.
- Строка «риск → тогда». Планирование «если, то», его упоминает Кулиева в методах веры в себя, и его же Клир называет намерением реализации. Заранее придуманный ответ на срыв заметно повышает шанс устоять.
- Строка «Якоря» в форме «после → ». Наслоение привычек, Клир, закон 1. Новая привычка цепляется к уже существующей, а не к абстрактному времени.
- Пять строк, не двадцать. Крошечный старт, Клир. Привычки писать план ещё нет, поэтому форма должна занимать пять минут.

## Правило «Блок кончился»

Решение 2026-10-23, по итогам первого дня. Когда время блока вышло, а задача не закончена: останавливаюсь и иду дальше по плану. Блок следующей задачи не отдаю. В запись дня пишу, сколько времени задача заняла на самом деле, и в следующий раз закладываю больше. Оценка времени придёт с опытом; первые недели считаем её данными, не ошибкой.

Источник: Ньюпорт, тайм-блокинг (план пересматривается, а не тащится молча). Конкретное правило остановки наше, не из книги.

## Как я оцениваю присланный план

Чек-лист «вера в план» из листа Кулиевой, семь пунктов. Я отвечаю на каждый по твоему плану:

1. Знаю первый шаг, который можно сделать уже сегодня.
2. Знаю, сколько времени займёт.
3. Знаю, какие ресурсы нужны.
4. Знаю, какие препятствия могут возникнуть.
5. Знаю, как измерить прогресс.
6. Знаю, к кому обратиться за помощью.
7. Знаю, как выглядит успешное завершение.

Оценка: 6–7 хороший план, 4–5 нужны уточнения, 0–3 слишком абстрактный, переписываем вместе. Для дневного плана достаточно пунктов 1, 2, 4, 7. Для недельного и для планов на месяц смотрим все семь.

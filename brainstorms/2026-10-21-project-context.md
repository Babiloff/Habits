  - Тип А, «был план, но не придержался»: проспал утреннюю тренировку -> плохо позавтракал -> соцсети, не вышел на улицу (хотя любит гулять, «жизненная цель: как можно больше всего увидеть») -> поссорился с кем-то (нагрубил папе по телефону или поссорился с Лизой) -> «хочу же быть классным чуваком, классным сыном, почему нагрубил» -> разочарование -> никакой проактивности -> вечером опустошение, «время прожито зря».
  - Тип Б, «не было плана, заполнял пространство»: немного прибрался, немного спорта, немного поработал, «всё немножко», «просто заполнил пространство», к глобальной цели не продвинулся -> усталость и разочарование, «всё как будто ни о чём».
  - Ключевая фраза: **«не продвинулся к своей цели, хотя я чётко не осознаю, что есть моя цель»**.
- Выводы для системы:
  1. Разница между хорошим и плохим днём у него почти целиком = **наличие плана накануне и следование ему**. Это главный рычаг, подтверждён третий раз (Q1, Q4, Q5).

  3. Срыв по цепочке (проспал -> завтрак -> соцсети -> ссора): первая костяшка — утро. Утренняя рутина защищает весь день.
  4. Новые ценности, прозвучавшие впервые: прогулки, «увидеть как можно больше»; быть хорошим сыном (отношения с отцом).
  5. Цель не осознана чётко -> работа с ценностями (ACT-вопросник) не факультатив, а необходимое условие, чтобы трекер имел смысл.
- Флаги:
  - Конфликты с отцом и Лизой как часть плохого дня -> тема для сферы «семья/партнёрство» в вопроснике ценностей.
  - Три цифры диагностики по Кулиевой пока не даны -> пользователь.

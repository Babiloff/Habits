# Неделя 1 из 12 (пн 26.10 – вс 01.11)

Главная цель: отправить 5 CV.

## Пять тактик
1. CV, 5 × 30 минут, первым блоком рабочего дня. Пн отбор 8–10 вакансий и базовое CV, вт–пт по 1–2 отправки.
2. Налоговый вопрос: найти срок в письме, список вопросов бухгалтеру или налоговой, первый шаг по декларации.
3. Оптимизация конверсии сайта: 3 часа, две сессии по 1,5 часа (ср, чт).
4. Film Lab регулярка: закупка камер 3 вечера по 30–45 минут (пн, ср, чт) и две сессии контент-плана по 45 минут.
5. Досуг и семья: 2 часа планирования выходных в пятницу вечером.

## Малые шаги (по разу, до часа)
Купить книгу; первый вечерний тест; список «добавочная ценность на текущей работе» (45 мин); план прокачки Claude Code (60 мин); шаг по регистрации фирмы, если закрыт налоговый шаг. Футбол с Алексом по погоде, вне плана.

## Привычки
Йога 15 минут (минимум 5); растяжка спины 5 упражнений (поясница); вечерний план. Утренний блок «тело»: кофе, йога, растяжка.

## Ротация главной задачи дня
Пн налоговая; вт работа + контент-план; ср и чт сайт; пт Claude Code + фирма. Сб, вс свободны.

## Правила недели
Остановка по окончании блока (см. daily-plan). Выпадает первым: контент-план, потом сайт. Цель недели 85 %, не 100.
